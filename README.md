# THA カップ設置角・透視写真計測

[アプリを開く](https://shimizutom1981-ship-it.github.io/THA-Combined-Anteversion-Calculator/)

## 機能
- 写真計測：基準線H1–H2、カップ長軸A–B、短軸側の点Cによる5点計測。RI・RAを表示します。
- 目標角・幾何シミュレーション：ステム前捻角、ΔPT、外方傾斜角から計算し、左右の投影像を表示します。
- 研究用PSTI：仰臥位・立位のPACS距離（mm）を1回または3回平均で入力し、後傾変化量を推定します。JSON/CSV保存、JSON再読込に対応します。

## 実装されている式
- 中間位目標RA = 37.3 − 0.7 × ステム前捻角、中間位目標RI = 入力RI。
- 後傾正のΔPT = 立位PT − 臥位PT、d = ΔPT / 2。
- 中間位のカップ軸 n = (cos(RA) sin(RI), sin(RA), cos(RA) cos(RI))。座標は同側外側・前方・上方。
- 臥位軸 = (nx, ny cos(d) − nz sin(d), nz cos(d) + ny sin(d))。
- 臥位RA = atan2(y, hypot(x,z))、臥位RI = atan2(x,z)。計算時はラジアンを用いる。
- 図の開口長軸傾斜はradiographic RIそのもの。RAのcosを追加で掛けない。

ΔPT/2を直接前捻から引く旧方式は比較表示のみです。入力RIは従来の臥位固定値から「中間位の目標RI」に意味が変わっています。前後傾のみの剛体回転が対象で、可動域最大化や臨床転帰を検証した式ではありません。

例：ステム20°、ΔPT10°、中間位RI40° → 中間位RA23.3°、臥位RA19.43395799°・RI38.75810880°。
- PSTI推定ΔPT（後傾正）= 0.74 ×（立位PSTI − 仰臥位PSTI）− 1.2

PSTIは研究用・自施設未検証です。シミュレーターへ自動転記しません。計算結果のみで臨床判断を行わないでください。詳細な適用条件・限界はアプリ内に記載しています。

## データと起動
画像と入力値はブラウザ内で処理し、アプリからサーバーへの送信は行いません。保存操作で端末へダウンロードします。患者氏名などの識別情報を入力しないでください。

ビルド不要の静的アプリです。index.htmlとassets/を同じ階層に配置して配信してください。

## 2026-11-06 計測安全性の修正
重複基準点・長軸点、非有限座標、短軸が長軸を超える打点では角度を表示しません。C点は中心を通る短軸とrimの交点に置き、長軸方向へずれた場合は警告します。垂直投影は任意のrim点から真の短軸を復元するものではなく、式自体は変更していません。画像切替・失敗時は旧計測を消去し、古い読込完了が新画像を上書きしないようにしました。後捻でも軸比は非負で表示し、ページ拡大制限を解除しました。
回帰テストは合成座標とDOM/Image doublesによるものです。iPhone実機、カメラ、EXIF回転、OS文字拡大、マルチタッチは別途実機確認が必要です。臨床妥当性の検証ではありません。


## 2026-11-07 offset 機能追加（研究用試作）
写真を選び、写真計測内の「Femoral / global offset（2D AP・研究用）」を開きます。既存のカップ・脚長差の打点と独立した専用画像上で、画像左／右を選んで計測します。

- 骨頭輪郭3点から円中心を求めます。カップ開口部の楕円中心は流用しません。
- 骨幹の離れた2断面で対向する皮質を2点ずつ取り、各中点を結んだ軸を使用します。FOは骨頭中心からその延長線への垂直距離です。
- 両側骨性涙滴U字輪郭の最下点を骨盤基準にします。AOは同側点を通る涙滴間線への垂線から、骨頭中心までの外側距離です。閉鎖孔代替点はこのAO/GOには使いません。
- GO = FO + 涙滴最下点基準AO。FOとAOは方向が異なるため単一の水平線分とは限らず、骨盤正中線を用いる定義とも区別します。
- 未校正はpxのみ。独立した校正2点、実物の既知長、確認チェックが揃った場合のみmmを表示します。カップ外径校正は校正源で選んだ場合のみ使用します。既知長の初期値は空欄です。校正点・長さの変更で確認を解除します。
- 不足点、重複・不安定な骨頭3点、無効な軸、逆順の涙滴、内側向きAOを検出します。無効なAOでもFOは独立して表示できます。
- 画像変更・読込失敗・点リセットでoffset、校正、確認状態を消去します。
- JSONに打点・結果・定義、CSVに両画像側のpx/mm・定義・警告を保存します。画像と患者識別情報は含めません。JSON再読込はこの版にありません。

配信時には index.html、offset-geometry.js、cup-calibration.js、offset-ui.js、assets/ を同じ階層構成で配置してください。

- `node tests/point-gesture.test.cjs`
- `node tests/offset-browser.test.cjs`（Playwright＋Chromium環境が必要。今回の環境では起動制限のため未実行）

検証範囲：合成座標による計算、左右反転、回転・倍率不変性、欠測・不正値、DOM doublesによる打点／長押し／Shift／複数ポインタ中断、校正・消去・保存を確認。実ブラウザでの表示と操作、Android/iPhone実機、実画像での臨床妥当性は未検証です。診断・治療・手術判断には使わないでください。


## カップ外径 A–B 校正
実際に使用したカップの外径を入力し、その径に対応する円形外縁の投影楕円の長軸両端がA/Bであることを確認した場合に限り、外径(mm) ÷ A–B(px) を任意の参考倍率にできます。余分なcos補正は加えません。

既存A/Bは「開口縁の長軸両端」のため、外側リムの実径と対応するとは限りません。内側リム、ライナー、骨頭、リーマー径、メーカーのサイズ呼称を外径と同一視しないでください。カップ形状・コーティング・フランジなどでも対応が変わります。対応を確認できない場合は専用S1–S2を使います。校正目的でA/Bを別輪郭へ移すと既存RI/RAも変わります。

- 脚長差とoffsetで校正源をそれぞれ明示選択します。選択した源が無効ならpx表示となり、別源へ自動フォールバックしません。
- 手動の既知長・校正点は源の切替で保持します。従来の仮の32 mmは初期値から除去しました。
- A/B座標または外径が変わると、確認時の幾何スナップショットと照合して確認を解除します。Cだけの変更は解除しません。
- 画像切替・読込失敗・点リセットではカップ径と確認を消去します。
- JSON/CSVに実際に選択した校正源、入力径、倍率、不確実性を保存します。JSONにはA/B座標・px径・確認状態も記録します。

円形外縁の平行投影で長軸が実径を保つ前提です。X線の透視投影、撮影した画面の遠近歪み、縦横比の変形、カップと大腿骨／対側股関節の深さの差による倍率誤差は残ります。ユーザー確認は臨床精度の検証を意味しません。

`node tests/cup-calibration.test.cjs` と `node tests/offset-ui.test.cjs` で数式・校正源・失効・保存・脚長差への適用を検証します。

## 2026-11-08 PSTI 写真打点
写真計測の PSTI パネルに、左右涙痕、左右坐骨先端、恥骨結合上縁の独立5点を追加。
- 坐骨先端：涙痕間線への下方垂直距離が最大となる輪郭点を左右別に手動選択（ユーザー指定）。輪郭全体の自動検出・最大点保証はしません。
- PSTI：左右坐骨点を結ぶ線から恥骨結合上縁への符号付き垂直距離。上方が正。涙痕間線は点選択の基準です。
- 旧い未指定「恥骨結合」点とは異なる `pubicSuperior` として保存。教師データ、旧点、既存PSTI手入力を暗黙に流用・再解釈しません。写真PSTIのJSON読込は未実装です。
- 未校正はpx。専用既知長または明示的に選択したカップ外径校正の確認後だけmm。校正変更で確認を解除。カップと骨盤の深さの差による倍率誤差に注意。
- JSON/CSVに定義・撮影日・姿勢・研究ID・座標・校正・距離を保存。画像は含みません。画像変更・失敗・全打点リセットで消去。
- 経時変化の角度推定は追加していません。既存の術前仰臥位→立位推定式を術後の時間差へ転用しません。異なる画像のpx差を比較してはいけません。
出典：Muir et al., [Cureus 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6939981/)。点の追加選択規則と本アプリの臨床妥当性は未検証です。
配信時には `psti-photo-geometry.js` と `psti-photo-ui.js` も同じ階層に配置します。

検証：`node tests/psti-photo.test.cjs`、`node tests/psti-photo-ui.test.cjs`。
